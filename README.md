# Codex Long-Running Tasks Plugin

This repository contains the `long-running-tasks-plugin`, a local compatibility
plugin that runs explicit repository plans as isolated, verifiable, recoverable
Codex slices.

See the [plugin README](plugins/long-running-tasks-plugin/README.md) for
preparation, MCP and CLI examples, approval modes, testing, and recovery.
The [canonical workflow guide](plugins/long-running-tasks-plugin/docs/workflow.md)
describes the triage/spec/ticket/run record, serial scheduling, pinned
Matt-tools bundle, reconciliation, and recovery boundaries.
